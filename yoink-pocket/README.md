# Yoink Pocket Android build
Isolated Android project; built on `yoink-pocket-build-20261112` branch without modifying the default branch source.
- Android 10+ / ARM64
- yt-dlp + FFmpeg local processing; download needs Internet.
- Share links or paste URLs.
- Video quality: best / 1080p / 720p / 480p; MP3 audio.
- Completed media goes into MediaStore, Movies/YoinkPocket or Music/YoinkPocket.
- This unofficial prototype is not affiliated with Yoinks.
- Some websites prohibit downloads or use DRM/authentication unsupported by this app.
- Only download media you have permission to retain.
- Dependency GPL-3.0, so distribution must comply with that license.
Run the workflow on the branch; find APK under Actions run > Artifacts.
